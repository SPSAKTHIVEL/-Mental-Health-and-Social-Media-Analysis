# 🧠 Mental Health and Social Media Analysis

This project analyzes the relationship between social media usage and mental health using data science techniques. The goal is to explore patterns, identify potential correlations, and gain insights into how social media behavior may impact mental well-being.

## 🚀 Project Overview
The project performs exploratory data analysis on a dataset containing information about social media usage, user behavior, and mental health indicators. The analysis focuses on identifying trends and patterns in the data.

## 📂 Dataset
The dataset contains information related to social media usage and mental health factors. Key features include:

- Age
- Gender
- Time spent on social media
- Social media platform usage
- Sleep patterns
- Stress levels
- Mental health indicators

## 🔎 Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Social media usage pattern analysis
- Correlation analysis
- Data visualization

## 🛠️ Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
